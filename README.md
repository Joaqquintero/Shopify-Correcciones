En este código se solucionó el problema principal de la empresa VIRIATHUS donde en su Shopify tuvieron el inconveniente de que, al ser una tienda de antigüedades y tener piezas únicas, no podían: <br>-Recibir un pago sin saber si el articulo esta disponible. <br>-Calcular un envío por defecto.<br>Por lo cual se realizo una vinculación entre el carrito que Shopify genera, los draft orders de Shopify para que en el caso de que la persona quiera modificar algo en el mensaje que Whatsapp genera quede el precedente en draft orders de productos que le interesaban y precio final. El cual tambien es utilizado para pasar a order y cobrar a travez del link de pago de Shopify, y un mensaje de Whatsapp donde se envia la informacion de lo que desea comprar, el precio final a pagar y dependiendo el caso la información de donde se realizará el envío para poder cotizárselo.<br>Esto se realizo creando una app desde cero en el Dev de Shopify y mediante una API transferir la información a Whatsapp creando primero el draft order. <br>Tambien se añadió un formulario con lector de PDF para los casos donde el cliente requiera factura, en el caso de que la respuesta sea si el cliente solamente adjunta el PDF y el lector rellena los campos con la información que se necesita y se guarda en el draft order.
